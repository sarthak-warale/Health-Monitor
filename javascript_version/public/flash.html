Device setup

Install ESP32 firmware

Connect your ESP32 DevKit/WROOM with a USB data cable, then choose the serial port below. Keep the board connected until installation finishes.

Use desktop Chrome, Edge, or Firefox with Web Serial support. USB flashing needs a secure HTTPS page (or localhost).

Before this button can install firmware, build the sketch with your private device settings and publish the generated files in public/firmware/. After flashing, connect the MAX30102 and open the serial monitor at 115200 baud to check Wi-Fi and sensor status.
